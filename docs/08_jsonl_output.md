# Step 8: JSONL Output Format and Submission

## Required JSONL Files (7 total)
All files live in `results/` folder:

1. `dev_baseline.jsonl`
2. `dev_A.jsonl`
3. `dev_B.jsonl`
4. `dev_C.jsonl`
5. `dev_final.jsonl`
6. `heldout_baseline.jsonl`
7. `heldout_final.jsonl`

### Each Record Structure
```json
{
  "question_id": "q-example",
  "target_paper_id": "paper-17",
  "retrieved": [
    {"rank": 1, "chunk_id": "paper-17:c12", "paper_id": "paper-17",
     "score": 0.82, "text": "The authors used dropout.",
     "source_spans": [{"paragraph_id": "s0:p4", "start": 0, "end": 25}]},
    ... (9 more chunks, ranks 2-10)
  ],
  "answer": null,              // null for dev/heldout retrieval questions
  "abstained": null,           // null for dev/heldout retrieval questions
  "latency_ms": 180,           // retrieval-only latency
  "llm_calls": 0               // 0 for retrieval-only questions
}
```

### 10-Chunk Requirement
- **Exactly 10 unique chunks** ranked 1–10
- **Combined text length** of the 10 chunks must be **at most 12,000 characters**

### source_spans Format
- Must point into the **original paper**
- Paragraph IDs like `"s0:p4"` (section 0, paragraph 4) or `"abstract"`
- Zero-based character offsets: `start` (inclusive), `end` (exclusive)
- Example: `{"paragraph_id": "s0:p4", "start": 0, "end": 25}`

### Development Questions vs Held-Out Questions
- **Dev/heldout (retrieval only)**: `"answer": null`, `"abstained": null`
- **The 20 fixed questions**: `"answer": "<string>"`, `"abstained": true/false`
  - **Deliberate refusal**: `answer=""` and `abstained=true`
  - **Normal case**: nonempty `answer` and `abstained=false`

### JSONL File Generation
Generated by `scripts/run_experiment.py` with different `--name` and `--retriever` configs:
- `dev_baseline.jsonl`: Baseline (fixed chunks + dense)
- `dev_A.jsonl`: + Structure-aware chunking (A)
- `dev_B.jsonl`: + Dense + BM25, RRF (B)
- `dev_C.jsonl`: + Cross-encoder rerank (C)
- `dev_final.jsonl`: + All three (A + B + C)
- `heldout_baseline.jsonl` / `heldout_final.jsonl`: Held-out split

### Validation (`scripts/validate.py`)
- Checks JSONL format compliance
- Reports any missing fields or malformed records
- Can be run: `python scripts/validate.py results/dev_baseline.jsonl`

### Score Answers (`scripts/score_answers.py`)
- Reproduces reported metrics from JSONL outputs
- For dev files: Recall@5/10/MRR@10 (union and single 80% coverage)
- For held-out files: Answer F1, gold-unanswerable count, false-answer rate
- Usage: `python scripts/score_answers.py results/dev_baseline.jsonl`
